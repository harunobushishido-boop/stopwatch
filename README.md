# 集中時計 × Webタイマー

GitHub Pagesで公開する静的Webアプリです。

## 主な機能

- 時計：国・地域の現在時刻を表示
- タイムゾーン設定：自動・各国/地域・UTCを選択
- タイマー：プリセット、時分秒、連続実行、保存、終了通知
- ストップウォッチ：ラップ計測と履歴の保存（ブラウザー内）
- 共有ノート：以前からの固定共有ノートリンクを1秒ごとに読み取り、予定・持ち物の自動音声発表と大画面表示（Googleログイン不要）
- 天気予報：Open-Meteoのみを使用し、現在値・時間別予報・7日間の予報を表示
- BGM・背景・PWA対応

## 共有ノート

共有ノート欄には「設定済み」と表示し、以前から設定している固定の共有ノートをそのまま使います。新しい共有ノートの作成、共有リンクの生成、書き出し、ダウンロード機能はありません。アプリはGoogleログインやSheets APIのOAuth許可を要求せず、公開閲覧できる元の共有ノートから1秒ごとに予定・持ち物を読み取ります。内容の編集は元の共有ノート側で行います。

## 天気予報

Open-Meteoから現在値、気温、天気コード、降水確率、湿度、風速、7日間の最高・最低気温を取得します。取得に失敗した場合は最大72時間以内の保存済み予報を使用します。週間予報には日付と曜日を表示します。

GitHub Pagesではリポジトリのルートを公開対象にしてください。
