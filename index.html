はじめての方へ
集中時計の使い方

ブラウザだけで動く、完全無料の世界タイマー画面＋作業用BGM＋おしゃれデジタル時計。iPhone・iPad・Mac・PC・Android全対応。下のツールバーから4つの機能にアクセスできます。

  • 世界時計国・地域を選んで、その地域の現在時刻を表示できます。タイムゾーンの切り替えもワンタップで行えます。
  • おしゃれ背景・配色美しいランダム配色（背景・文字・アクセントの3色）をベースに、写真風プリセットや独自画像のアップロードも可能。
  • 作業用BGM・集中音楽集中に向いた作業用BGMと環境音を46種類内蔵。雨音・波・焚き火・ホワイトノイズなどから選び、ポモドーロタイマーと組み合わせて勉強・在宅ワーク・作業中の集中環境を整えられます。
  • 世界時計・タイムゾーン切替設定から世界各都市のタイムゾーンに切り替えられます。海外との打ち合わせや旅行先でも便利。
ホーム画面に追加 / アプリ化
Windows / Mac（Chrome）
  1. アドレスバー右側の「アプリをインストール」アイコン（⊞ もしくは ↓）をクリック
  2. 「インストール」を確定するとデスクトップアプリとして起動します
  3. そのまま F キーまたは「全画面表示」でフルスクリーンに
  4. セカンドモニタや常時電源のサブ画面に置くと最高

設定はあなたのブラウザのローカルストレージにのみ保存され、サーバーには送信されません。
